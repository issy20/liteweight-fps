# 壁際の改善（M2の続き、M3は着手しない）

対象: 壁・遮蔽物に接触した際の「画面が物体色で埋まる」問題の切り分けと改善。
M3の武器機能・射撃・ADSには着手しない。製品版の黒帯なし表示（M6）も今回変更しない。

## 切り分け

- **A. 実際のめり込み:** 視点や衝突形状が物体内部に入る。
- **B. 近距離の単色面:** 正しく衝突して止まっているが、壁面が画面を占める。

コード確認済みの不整合:
`Player.position` を視点位置（view_matrixのeye）と身体中心（collides）の両方に使っている。
EYE_HEIGHT=1.6 / PLAYER_HEIGHT=1.8 のため、接地時の垂直判定範囲が `1.6±0.9` = 0.7〜2.5mとなり、
意図する足元0〜頭頂1.8mと0.7mずれている。これは修正対象だが、単色化の直接原因と断定せず検証する。

## 合意した改善順序

1. 衝突判定と視点位置の整合性の確認・修正
2. 近距離でも識別できる控えめな表面模様の追加
3. 必要に応じた接触距離・壁沿い移動の調整

## 実装要件

- 足元・身体中心・視点位置を明確に区別し、身体高さと視点高から一貫して算出する。
- 正面・斜め・角への接触、歩行・ダッシュ・ジャンプでもめり込みを防ぐ。
- 壁沿いの移動で不自然な引っ掛かりや振動を起こさない。
- 壁と遮蔽物に、薄い格子・パネルの継ぎ目・帯などの軽量な模様を追加。
- 模様は敵の視認性を妨げない。シェーダーによる生成を候補とし、実測して判断する。
- 接触距離の拡大は補助策。衝突半径を大きくするだけで解決扱いにしない。
- カメラの自動後退や接触時のFOV変更を標準の解決策にしない。
- M0の比較実装と保存済み測定データを保護する。表面模様はbench-wgpu/miniquadに影響させない。

## 実装と検証（2026-09-28）

### 切り分けの結果

ユーザー報告「壁・遮蔽物にぶつかると画面全体が物体色で埋まる」について、
コードと実機で確認した結果、以下の2要因があった。

1. **めり込み:** `Player.position`（視点1.6m）を衝突判定の身体中心として使っていたため、
   垂直判定範囲が0.7〜2.5mとなり、意図する足元0〜頭頂1.8mと0.7mずれていた。
   身体の下部0〜0.7mが判定から漏れ、低い障害物（高さ0.5mの段差など）を突き抜けていた。
2. **近距離の単色面:** 正しく衝突して止まっていても、壁面が画面を占めると単色に見える。
   初回の試作（線幅6cm・10%暗く）は「雑」と評価され、いったん外した。その後の評価で
   「細ければあってもいい」とのことだったため、線幅3cm・最大6%暗くの控えめな格子線を採用した。

### 修正内容

- `src/simulation/player.rs`:
  - `foot_height()`（足元）と`body_center()`（足元+PLAYER_HEIGHT/2）を追加。
  - `collides`の判定を視点位置ではなく身体中心に変更し、垂直判定を足元0〜頭頂1.8mに統一。
  - `COLLISION_EPSILON`を導入し、f32の丸め誤差（壁面からちょうど半径の距離）で
    誤って接触扱いになるのを防いだ。これで壁沿いの移動が引っかからなくなった。
  - `move_with_collision`で、落下中の衝突を着地と判定するよう修正。
    これで着地後に再度ジャンプできるようになった（修正前は1回しかジャンプできなかった）。
- `assets/shaders/scene_wall.wgsl`: 壁面識別用の細い格子線。
  WGSLの`dpdx`/`dpdy`から面の法線を求め、水平面はワールドx/z、垂直面は高さyを含む格子を描く
  （1m間隔・線幅3cm・shade0.94）。`src/engine/renderer.rs`はこのシェーダーを参照。
- `src/engine/mod.rs`の`grid_shade`: シェーダーと同一の格子計算をRustで再現（テスト用）。
  法線とワールド座標を受け取り、水平面/垂直面で格子軸を変える。
- `tests/m2.rs`: テストを5件追加（身体中心・低い障害物・正面/斜め/角・ジャンプ中の壁接触・
  壁沿いスライディング・再ジャンプ・grid_shade）。合計17件。
- `tests/m1_gpu.rs`: 表面模様（最大6%暗く）が掛かっても検証が壊れないよう、
  中央ピクセルの検証を「赤成分が支配的（230以上）」に緩めた。

### 検証結果

- 通常Rustテスト30件（core 9 / M1 4 / M2 17）、GPUテスト2件（実機GPU・Metal）成功。
- fmt / Clippy / Releaseビルド成功。`--smoke`は終了コード0。
- Pythonテスト4件成功。
- ユーザー実機確認: 「基本的には合格。ジャンプが一回しかできない」→ 修正後に全項目合格。
  模様は「細ければあってもいい」との評価で、細い格子線を採用。
- M0の比較実装（bench-wgpu/miniquad）と保存済み測定データは今回変更していない。
- Windows / Linux X11・Wayland / Intel Macの実機確認は後続課題として残る。

**壁際の改善は完了。** 単色化の主因は身体中心のずれによるめり込みであり、修正済み。
近距離の面の識別には細い格子線を採用した。次はM3（ARの完成: ADS、連射、反動、リロード、射撃・命中演出）へ。
