# M5: BOT撃ち

## テストリスト

- [x] 初期状態で5体がスポーンし、Static / Strafe / Chaseが含まれる。
- [x] Staticは静止し、Strafeは往復し、Chaseはウェイポイントを経由してプレイヤーへ近づく。
- [x] AI判断は20Hzで更新し、位置更新は固定シミュレーション刻みで滑らかに進む。
- [x] BOTは壁・遮蔽物・他BOTへ重ならず、遮蔽物を通り抜けない。
- [x] 頭部と胴体へ命中し、ダメージ倍率・命中・ヘッドショット・キル数を更新する。
- [x] 死亡中のBOTは描画・命中対象から外れ、待機時間後に再スポーンする。
- [x] リスポーン地点は8m以上離れた有効候補からランダムに選び、遮蔽物を優先し、既存BOTとの重なりと同一BOTの連続重複を避ける。
- [x] BOT外観を一から低ポリゴン人型マネキンとして構成する。胸・腰・骨盤に形状差のある胴体、肩から手首までの腕、膝・足先を分けた脚を共有メッシュで描く。頭部は全高の約1/8、脚は約半分、肩幅は胸郭より広くする。単体200頂点以下、頭部・胴体の外観とヒットボックスが対応する。

## 実装方針

- 既存の`Combat`とヒットスキャンを保ち、`Target`を行動・生存状態を持つ軽量BOTへ拡張する。
- 初期5体は独自の低ポリゴン形状を共有し、設定画面はM6で実装するため本マイルストーンには含めない。
- Staticは停止、Strafeは固定範囲を左右移動、Chaseは少数の手動ウェイポイントと簡易衝突回避で接近する。
- 死亡したBOTは2秒後に復帰する。リスポーン候補はプレイヤーから8m以上離れた有効地点からランダムに選び、遮蔽物の背後を優先し、生存BOTとの重複と同一BOTの連続重複を避ける。Tracking Aimは従来の専用選定を維持する。

- 変更理由: 決定的な候補巡回をセッションごとに異なるランダム選択へ変え、リスポーン位置の反復を避けるため。
