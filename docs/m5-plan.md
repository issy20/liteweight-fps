- [x] 箱形の仮表示を、共有する細身の人体模型モデルへ置き換える。身長を保ったまま頭部を小さくし、丸みのある体幹・先細りの四肢・額の小さな識別マーカーを使う。頭部・胴体の外観とヒットボックスが対応する。

## 実装方針

- 既存の`Combat`とヒットスキャンを保ち、`Target`を行動・生存状態を持つ軽量BOTへ拡張する。
- 初期5体は独自の低ポリゴン形状を共有し、設定画面はM6で実装するため本マイルストーンには含めない。
- Staticは停止、Strafeは固定範囲を左右移動、Chaseは少数の手動ウェイポイントと簡易衝突回避で接近する。
- 死亡したBOTは2秒後に復帰する。リスポーン候補はプレイヤーから8m以上離し、遮蔽物の背後を優先し、生存BOTとの重複を避ける。
