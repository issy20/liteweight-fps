# M1 最小3Dエンジン

範囲: wgpuによる床・壁・遮蔽物の描画、固定内部解像度、リサイズ、深度処理、終了・復帰。
M2のFPS操作・衝突、武器・BOT AIは追加しない。カメラは確認用の周回表示のみ。
M0ベンチマークは比較基準として保持する。

## テストリスト（1シナリオずつRed→Green）

- [x] 表示サイズが変わっても内部解像度と投影比率を保ち、転送時に縦横比を維持する
- [x] 幅または高さ0では描画せず、非0サイズへの復帰で再開できる
- [x] 内部解像度の変更は有効値のみを受け付け、表示領域を再計算する
- [x] アリーナの床・四方の壁・6個の遮蔽物が有効なインデックスで構成される
- [x] GPU実描画で手前が奥を隠す（描画順を逆転しても同じ結果）
- [x] GPUで内部解像度変更後も色・深度の寸法が一致し描画できる
- [x] fmt / Clippy / 全テスト / Releaseビルド
- [x] Releaseで起動・ウィンドウリサイズ・最小化/復帰・終了を実機確認
- [x] 同一M0シーンによる変更前後の性能を確認し、結果・制約を記録

実装方針: M1のレンダラーはシーンとカメラ行列を受け取り、計測器やゲーム状態に依存しない。
表示先と内部カラー・深度を分離し、内部解像度変更時はカラー・深度・転送バインドを一緒に作り直す。
通常のリサイズでは内部ターゲットは再作成しない。黒帯を用いて表示時の歪みを防ぐ。

製品版の方針（ユーザー指定）: 表示領域に合わせて内部解像度と投影比率を更新し、黒帯なしで表示する。
M6の表示設定で実装する。M1の黒帯付き表示は検証用の挙動であり、製品版の完成形ではない。
詳細は[SPECIFICATION.md §2.1](../SPECIFICATION.md#21-製品版の画面比率と内部解像度)を参照。

- 通常のRustテスト13件成功（既存9件＋M1の4件）。Clippy / fmt / Releaseビルド成功。
- GPUテスト2件をApple M1 / Metalで明示実行し成功。
  深度による遮蔽を描画順の両方で検証し、内部解像度の繰り返し変更後に中央の色と黒帯を読み戻した。
- Release `--smoke`は終了コード0。実際の表示サイズ変更は
  1920×1080 → 1280×960 → 1600×1598 → 2400×1000 → 1920×1080。
  800×800論理サイズの要求に対してOSが1600×1598物理サイズを返したが、その実寸で描画先を再構成して正常終了。
- 0サイズからの復帰はAPI経由で確認。実際の最小化・復帰と目視確認はユーザーの確認待ち。
- GPUを取得できないサンドボックス内ではGPUテストは失敗し、サンドボックス外の実機GPUで成功した。
  Windows/Linux/Intel Macの実機確認は未実施。

## 設計上の判断

M0の描画実装は比較基準として固定し、M1側は計測器に依存しないSceneRendererとSurface管理へ分離した。
M0シーンの頂点・インデックス・カメラ・統計の定義は変更していない。
M1の通常起動ではダミーを除いたアリーナのみを表示する。
内部解像度変更は有効値とGPU上限を確認してから関連リソースをまとめて置き換える。
Surface Lost/Outdatedは再構成、Timeoutは再試行、その他の描画エラーは非0終了で報告する。
画像を黒帯付きで表示し、リサイズによる投影の歪みを避ける。

## 性能回帰チェック

Apple M1 / macOS 15.6.1、Release、内部720p・表示1920×1080、M0シーン5ダミー、VSync on。
warmup 5秒＋30秒を各3回、M0→M1 / M1→M0 / M0→M1で実行。以下は各試行の中央値。
M0基準はM1着手前に保存したバイナリで、SHA-256をmanifestに保存。

| 実装 | 平均FPS | 1% Low | p99 ms | RSS MiB | 起動 ms |
|---|---:|---:|---:|---:|---:|
| m0 | 60.00 | 51.25 | 17.96 | 59.28 | 175.88 |
| m1 | 59.97 | 50.44 | 17.83 | 62.05 | 179.59 |

今回の小さいシーン・VSync on条件では、平均FPSとフレーム時間に明確な悪化は見られなかった。
VSyncの上限に近いため、最大描画性能や他OS・機種の回帰なしを保証する結果ではない。
計測中の熱・バックグラウンド負荷は厳密に統制していない。RSSは1秒間隔のサンプル最大値。
M1の通常プレビューはダミーなしだが、この試験ではM0と同じ形状・カメラ・統計を使った。

[manifest](benchmarks/m1-2026-09-27/manifest.json)と同ディレクトリのJSON/CSV/logを保存。
全6試行のCSVから平均FPS・p99・1% Lowを再計算し、JSONとの差が1e-5未満であることを確認。

## 手動確認

Release版を起動し、終了コード0を確認。以下の目視・実操作の合否はユーザー回答待ち。

- 床・壁・遮蔽物の見え方と遮蔽
- 縦長・横長へのウィンドウリサイズ時に歪みや欠けがない
- 1 / 2による720p / 1080p切替
- 最小化して復帰した後の描画再開
- Spaceによる確認用カメラの停止・再開
- Esc / Qによる終了

M1のコード・自動検証・性能確認は済み。手動確認が揃うまではマイルストーン完了扱いにしない。
