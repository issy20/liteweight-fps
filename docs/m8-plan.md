# M8: 最適化・配布

M8の成果物は、実測に基づく性能レポート、Windows/Linux/macOS向けReleaseパッケージ、OSごとの実機検証記録。M0描画ベンチマークは現在のゲームプレイ負荷を含まないため、ゲームの性能値として流用しない。

## タスク

- [x] 4ターゲット向けの再現可能なパッケージ生成とアーカイブ内容テスト。
- [x] CIのLinuxネイティブ依存を補い、Releaseパッケージをmatrix buildするworkflowを追加。
- [x] 実機を用意できないOSは、CIのビルド・自動テスト結果と実動作の未検証を明確に分ける方針を記録。
- [ ] GitHub Actions実行結果を確認し、Linux x64とIntel macOSのクロスビルドを確認。
- [ ] ゲーム本体のRelease負荷で5/10/20 BOT、720p/1080p、静止/移動/射撃を測定し、平均FPS、1% Low、p99、メモリを記録。
- [ ] 可能な実機が得られた場合、Windows/Linux/macOSの起動、マウス捕捉、表示、音声、終了を確認する。現在は実機環境がなく、各OSの実動作を未検証として扱う。
- [ ] 性能値から最低GPU/OS・製品上限を決め、製品向け署名と配布条件を確定。

## 今回の実行環境

- ローカル: macOS 15.6.1、Apple M1、Rust 1.98.1、aarch64-apple-darwinのみインストール。
- Releaseのローカルテスト・ビルドは成功。Apple Silicon向けMach-Oバイナリ（4,814,096 bytes）と配布tar.gz（1,882,287 bytes）を生成し、含まれるファイルを確認。
- Pythonのパッケージテストは4ターゲットのアーカイブ形式と内容を一時ファイルで検証。
- Windows、Linux、Intel Macのクロスビルド・実機操作は未検証。CI workflowを追加したが、GitHub Actions上ではまだ実行していない。
- 現在のベンチマークはM0シーン用。ゲーム本体のFPS、フレーム時間、メモリは未測定。
- `cargo run --release -- --smoke`はローカル環境でmacOS通知サービスのエラー後に終了せず、手動停止した。正常なゲーム起動確認として扱わない。

## 完了判定

全ターゲットのCI package build、自動テスト、利用可能な環境でのゲーム本体性能レポート、配布手順を揃えてM8の開発成果を完了扱いにする。実機がないOSの入力・GPU・表示挙動は未検証として明記し、対応済みと宣言しない。測定できないGPU時間や未実施のOSテストも未測定として残す。
