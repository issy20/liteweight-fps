# M3: ARと静止ターゲット

M4の武器切替やM5のBOT AIは追加しない。M0ベンチマークは変更しない。

## 操作の競合

- 左ボタン保持で600 RPM、30発、胴体25ダメージ。空撃ちは弾・演出を発生させない。
- Rで2秒リロード（予備弾は無限）。満弾時は無効。リロードを射撃で中断しない。
- リロード開始でADS解除。リロード完了後は右ボタン保持に従いADSを再開。
- 移動・ジャンプ・ダッシュ中も射撃可能。移動中は拡散増加。
- ADS移行中も射撃可能。AR ADSは180ms、FOV70→60、感度倍率1→0.65。拳銃ADSはFOV70→62。
- Esc・フォーカス喪失で入力をクリアし一時停止。再捕捉のクリックは発砲しない。
- 視点反動と武器の見た目の反動を分離。命中射線は発砲前の視点を使用。

## 実装と検証記録（2026-09-28）

- 武器データと状態を`simulation/weapon.rs`、標的と射線判定を`simulation/combat.rs`に分離。
- 状態テストを一件ずつ追加し、失敗→実装→成功を確認。通常テスト38件成功（既存30件＋M3 8件）。
- `cargo fmt --check`、`cargo clippy --locked --all-targets -- -D warnings`、`cargo test --locked --all-targets`、`cargo build --locked --release --bins`成功。
- Apple M1 / MetalでGPUテスト3件（既存2件＋M3 1件）を明示実行して成功。制限環境内ではGPU取得に失敗し、実機アクセスが可能な環境で再実行した。
- Releaseの`--smoke`は4回のリサイズ・0サイズ休止・復帰・終了を実行して終了コード0。これは射撃操作・音の聞こえ方・5分連続プレイの検証ではない。
- 短い合成音5種類をrodio 0.20.1で再生。デフォルトの音声デコーダ機能は無効。音声デバイスがない場合は無音で続行する。
- 固定容量の動的GPUバッファを追加。通常プレイは静的アリーナ、標的／着弾、HUD、画面転送の計4 Draw Calls。M0比較用実装は変更していない。
- 標的はM3用の固定配置3体。HPが0になった瞬間に撃破通知を出してHP100へ戻す。BOTの移動・死亡・リスポーン管理はM5で実装する。

## 手動受け入れ手順

ユーザーがReleaseビルドで手動確認し、問題なしと報告。
以下は確認項目の記録であり、実行ログを取得したという意味ではない。

`cargo run --release`で起動する。

1. 正面の標的を左クリック。弾数が減り、射撃音・短い発光・反動が同期すること。保持して30発で止まること。
2. Rでリロード。進捗バーが進み、2秒後に30発へ戻ること。連射保持＋R、ADS保持＋Rも試す。
3. 右クリックでADSし、FOV・感度・武器表示が変化すること。素早い押下／解放や移行中の射撃も確認する。
4. 胴体・頭部・壁を撃ち分ける。白／黄／赤の命中表示と音、標的の一時的な色変化を確認する。壁越しでは命中しないこと。
5. ダッシュ・ジャンプと射撃を組み合わせる。Esc→左クリックで再開し、再捕捉のクリックでは発砲しないこと。フォーカス喪失・最小化後に移動や射撃が残らないこと。
6. 5分間継続してクラッシュ、入力喪失、目立つフレームスパイクがないことを確認する。
