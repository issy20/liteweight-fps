## 実装方針

- 既定の開始武器はAR。1/2/3で拳銃 / AR / スナイパーを選択する。
- 武器ごとに装弾数、射撃間隔、ADS、反動、リロード状態を持つ。
- 武器状態の選択は即時。画面では0.32秒かけてリロード中の武器を下ろし、新しい武器を構える。切替元のリロードを中断して装弾数を保ち、切替元と切替先のADS進行を0へ戻す。
- スナイパーのボルト操作は切替後もホルスター中に進み、操作完了前は再選択しても発砲不可。
- スナイパーのADS-inは400ms、ADS-outは200ms。連続進行度に応じてFOVは70°から20°へ、武器とスコープは照準位置へ線形に補間する。射線は腰撃ち時に視線から一定角度ずらし、ADSに合わせて視線へ収束する。スナイパーにはランダム弾拡散を使わない。別シーンの再描画はせず、既存HUDパスのアルファ合成でスコープ外をADS完了時に最大98%暗くする。
- 武器切替は0.32秒。前半で切替元を下げ、後半で切替先を構える。モーション中は移動・視点操作を維持し、射撃は受け付けない。
- 切替入力と同じイベント区間で発生した未消費のクリック押下は新しい武器へ引き継がない。フルオート武器の押しっぱなしは継続する。
