## 実装方針

- 既定の開始武器はAR。1/2/3で拳銃 / AR / スナイパーを選択する。
- 武器ごとに装弾数、射撃間隔、ADS、反動、リロード状態を持つ。
- 切替は即時。リロード中の武器を離れるとリロードを中断し、装弾数を保つ。切替元と切替先のADS進行は0へ戻す。
- スナイパーのボルト操作は切替後もホルスター中に進み、操作完了前は再選択しても発砲不可。
- スナイパーのADSは200ms。進行度85%（170ms）で低拡散へ到達し、FOVは70°から32°まで線形に補間する。別シーンの再描画はせず、HUD上の軽量なスコープ形状を重ねる。
- 切替入力と同じイベント区間で発生した未消費のクリック押下は新しい武器へ引き継がない。フルオート武器の押しっぱなしは継続する。
