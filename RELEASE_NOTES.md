# liteweight-fps 0.1.0 Preview

This is the first packaged preview of the offline single-player BOT training FPS.

## Included

- Free Training and Tracking Aim practice modes.
- First-person movement, mouse look, sprinting, jumping, and collision with the arena.
- Three original weapons with ADS, recoil, firing, reload, and weapon switching.
- Static, strafing, and chasing BOT targets with configurable population and behavior.
- Local settings for sensitivity, field of view, fullscreen, audio, ammunition, and BOT behavior.
- Windows x64, Linux x64, macOS Apple Silicon, and macOS Intel package builds.

## Preview limitations

- These packages are unsigned. macOS notarization and Windows Authenticode signing are not configured.
- Gameplay performance has not been measured on representative low-end hardware. No minimum FPS or GPU support is guaranteed.
- Runtime behavior has not been verified on all target operating systems. CI compilation and automated tests do not replace device testing.
- The Linux package is built on Ubuntu 22.04. Other distribution compatibility is not promised.
- Review `THIRD_PARTY_NOTICES.txt` and `DISTRIBUTION.md` for dependency notices and platform requirements.

This preview is for evaluation. Do not treat the listed platform builds as a claim of verified compatibility.
